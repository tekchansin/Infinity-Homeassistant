# Changelog

## 14.0-beta31
Extensions: programs and web sources add lyrics, album and artist information, covers, radio stations and menu items to Infinity Core — and Home Assistant shows each zone as a media player.

**Highlights**
- Extensions (Settings › Extensions): programs you run at home work with Infinity Core once you press Enable, and only as far as you allow. Web sources add lyrics, information, covers or radio from an https address. Find extensions lists the ones we know of.
- Home Assistant: the Infinity Core integration (HACS) shows each zone as a media player, with the cover.

**Improvements**
- Your amp: an extension can let Infinity Core's volume turn your amp and switch it on at the right input.
- Artist and album pages open with their information at once; pictures load ahead as you scroll, and the artist list shows one picture a visit; genre pages get their text overnight.
- Settings: tidier panels and shorter rows; the menu stays put while the page scrolls.
- For developers: the Infinity Core API, `pip install infinity-core-api` — anantarultimate.com/api.html.

**Fixes**
- TIDAL Hi-Res plays and seeks on older UPnP streamers.
