# Changelog

## 14.0-beta21
Clearer log reports when this app uses Infinity Core on another computer.

**Improvements**
- Send log report from an app that uses Infinity Core on another computer (Home Assistant, Umbrel, a NAS, another PC) now sends this computer's logs too — one code for both.
- Windows: the devices you share (Settings › Devices & Sharing) keep a log, and log reports include it.
- The log names the Infinity Link device that stopped taking music.
