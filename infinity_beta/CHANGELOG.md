# Changelog

## 14.0-beta17
Infinity Core on Umbrel, and a safer home server.

**Highlights**
- Umbrel: Infinity Core is in its own community app store. In umbrelOS: App Store › ⋯ › Community App Stores, add https://github.com/tekchansin/Infinity-Umbrel, then install Infinity Core (beta). Your music goes in Files › Downloads.

**Fixes**
- Infinity Core on a server with another app in front of it on the same box — Umbrel, Nginx Proxy Manager, a NAS's reverse proxy — now asks every browser and app on your network to pair, as it should. Before, a device on your network could use it without pairing. Update if your Infinity Core runs in Docker or on Umbrel.
